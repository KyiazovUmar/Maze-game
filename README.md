# RetroRay Maze Game

A simple 3D first-person maze game built using Python and Pygame. Navigate through the hallways, shoot targets, and find the green exit door to win.

## Controls

* **Move:** `W` / `S` or Up / Down arrows
* **Turn:** `A` / `D` or Left / Right arrows
* **Shoot:** `Spacebar` or Left Mouse Click
* **Quit:** `Escape`
